## What I'm building

VolkCell lets scientists upload microscope images and describe the analysis they need in plain English. It proposes a plan for approval, runs the analysis on GPUs and returns measurements, inspectable overlays, statistics and a report documenting the method.

It supports cell counting and viability, confluency, wound healing, spheroids and organoids, tube formation, retinal vessels and nanoparticles.

My work spans:

- **Product:** the web application and analysis workflow, from image upload to results.
- **Machine learning:** specialist imaging models, training pipelines and evaluation against expert labels.
- **Infrastructure:** GPU inference, backend services, authentication and billing.
- **Reproducibility:** recording the approved plan and method so analyses can be repeated.

I started coding the app in February 2026. For one CRO trial, I delivered four custom analyses in under two weeks: RPE phenotyping, tube formation, choroid explants and retinal vessels.
